# Security policy

ProjectN is a security assessment application. Please do not put exploit details, credentials, customer targets, or scanner output into a public issue or pull request.

If GitHub's **Report a vulnerability** option is available in this repository's Security tab, use it to contact the maintainer privately. Otherwise, open an issue asking the maintainer for a private reporting channel without including the vulnerability details. The maintainer can then arrange a private exchange.

Issues about ordinary setup failures, false positives, and feature requests may be reported through GitHub Issues. Include the operating system, ProjectN commit, relevant scanner version, and a redacted reproduction. Only use targets you are authorized to test.
